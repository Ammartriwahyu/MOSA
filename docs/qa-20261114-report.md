## 6. Risiko, keterbatasan dan tindak lanjut

- **Browser belum diuji ulang.** Pemeriksaan persetujuan otomatis menolak startup server pratinjau dengan pesan `blocked by policy` tanpa rincian lain. Tidak ada server aplikasi atau tab browser aplikasi yang sudah tersedia saat inventaris diperiksa. Tidak mengakali penolakan. Tidak mengklaim screenshot, responsive breakpoint/zoom/reduced-motion, LCP atau browser E2E dari build/JSDOM. Temuan browser P17 pada laporan lama adalah bukti rekan, bukan eksekusi audit ini.
- **Layanan nyata belum diuji ulang:** GoTrue/JWT/refresh/email, PostgREST/cloud migration, Gemini/foto asli, native push/VAPID/cron. Target/credential environment tidak diperiksa; env tidak dibaca. Suite memakai data fiktif dan provider fixture. Alternatif lanjutan: operator memilih proyek uji, kemudian menjalankan [checklist manual M01–M19](manual-test-checklist.md) tanpa membagikan rahasia di chat.
- **Perangkat nyata belum diuji:** Android/iOS, instalasi PWA, izin OS/kamera, orientasi/EXIF/HEIC, suara Indonesia lokal, screen reader, dua HP/sinkronisasi lintas tab/provider dan keterbacaan pengguna lansia. Status tersebut tidak berubah menjadi Pass.
- **SQL PGlite satu koneksi:** request HTTP paralel/replay dan constraint teruji, tetapi lock/race dua koneksi PostgreSQL/Supabase nyata masih perlu diuji. Pada kasus Q5 HTTP baru, waktu aktif baru dikendalikan fixture karena jam aplikasi tetap berbeda dari jam DB; trigger penentu waktu produksi tidak diganti. Tes SQL terpisah tetap memeriksa metadata trigger/pelestarian jam lama.
- **Pagar AI bersifat konservatif dan terbatas:** tetap bukan verifikasi medis/semantik menyeluruh, bukan sistem diagnosis, dan tidak menggantikan pop-up pemeriksaan manusia. Pengujian model nyata perlu data kemasan fiktif dan target layanan yang disetujui.
- **Dua warning lama tetap dicatat:** generator Node menampilkan `MODULE_TYPELESS_PACKAGE_JSON` saat memuat copy.ts; axe/JSDOM dapat mengeluarkan peringatan canvas tidak tersedia. Keduanya tidak menggagalkan suite/build; JSDOM bukan pemeriksa layout/kontras browser. Tidak menambah dependency atau mengubah tipe seluruh package hanya untuk membungkam warning.
- **Kesiapan rilis belum disimpulkan:** matriks tetap **20 Lulus otomatis / 6 Belum lengkap / 0 Gagal**. Celah assertion AC-09 verified 1/2→2/2 sudah ditutup; bukti perangkat/layanan AC-01/02/05/09/16/26 tetap diperlukan. Tidak menjalankan seed/reset akun, migrasi cloud, deploy, cron live atau tag freeze.

Semua tes akhir yang dijalankan lulus dan ketiga bug yang direproduksi sudah diperbaiki. Klaim “bebas semua masalah” memerlukan bukti perangkat/layanan di atas dan tidak dapat disimpulkan hanya dari suite otomatis.
